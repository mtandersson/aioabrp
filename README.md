# aioabrp

Async Python client for the A Better Routeplanner (ABRP) / Iternio telemetry
API. It will provide request/response access to the garage, catalog, and
current telemetry endpoints, plus a resilient SSE telemetry stream that
delivers extracted, typed metric values to consumer callbacks.

> **Status:** under initial development. Full usage documentation will arrive
> with the first real release.
